# 一定要到达那里

轻松诙谐的 2D 环境解谜与关卡编辑引擎，最终目标为 Steam。主角认准目的地持续前进，玩家通过物体、行为和事件改变环境，帮助他到达那里。

当前分支 `codex/spatial-2-5d` 的本地开发版为 **0.28.1 二维分层编辑器**。默认展示完整街区 [上班路 · 还得去](http://localhost:4173/?sample=chapter)：近街公交站 → 右侧向里过街 → 中街清障与车主追车 → 左侧窄巷电瓶车 → 远街早餐与狗 → 公司外门。约一分钟，使用者无需编辑。补齐站台等独立布景的行走层归属，修正被建筑遮住的问题；资源面板明确「层内显示顺序」。车辆入场与离场、行人半途被叫回、早餐落碗和公司门口终点继续保留。方案与限制见 [整章记录](docs/commute-chapter-layout.md)。

顶部「DSL 源码 / JSON」可直接修改当前关卡的物体、行为、规则与资源，提供校验、格式化、行列显示及应用后撤销。Ctrl+Enter 校验，Ctrl+S 应用到当前草稿；旧的导入为新草稿仍保留。源码只解析 JSON，不运行 JavaScript；在线与离线使用同一功能，见 [源码操作](docs/editor-engine.md#dsl-源码编辑)。

本地入口 [完整街区](http://localhost:4173/?sample=chapter)、[此路不借](http://localhost:4173/?sample=scooter)、[抬头看路](http://localhost:4173/?sample=crosswalk)、[借过一下](http://localhost:4173/?sample=tow-street)、[公交站片段](http://localhost:4173/?sample=bus-stop)、[模板练习](http://localhost:4173/?sample=templates)、[三个街口旧稿](http://localhost:4173/?sample=commute)、[局部连接样例](http://localhost:4173/?sample=layered)；离线文件为 `dist/gothere-editor.html`。默认新增并展示完整街区槽，已有草稿与后续编辑均保留。编辑仍分逻辑、资源与绑定校准三种视图。

清障片段「借过一下」继续保留：点击被占道车辆挡住的路人，他打电话叫来拖车；挂接清路后，端着早饭的车主追出店门。约24秒，数据与限制见 [清障片段记录](docs/tow-street-direction.md)。

此前的4种内置模板继续可用：完整街景背景、两种建筑、公交与队伍；活动组合保留行为、内部连线、帧动画和音效槽，可整体移动、复制或展开修改。模板练习从已铺背景开始，放入公交模板后可以直接试玩。导入任意素材包、保存自定义模板库和自动识图尚未实现，本轮暂缓这些扩展。

公交站使用统一视角、比例与色板的原创 CC0 矢量素材：连续远景/路面、整栋建筑、树池和站台，再叠加独立的公交、门和乘客。点击公交后队伍依次上车、车门关闭、整车驶出画面；不操作或过晚会撞到队伍。片段约17秒，无文字标语。场景分组用于筛选、隐藏和锁定；组合用于共同移动、复制和展开。普通物体可配置「移动中」图片/动画。方案与限制见 [公交站方向记录](docs/bus-stop-direction.md)和[模板操作](docs/editor-engine.md#素材模板与组合)。

三个街口的三层路线与七次操作原型作为旧稿保留，尚未根据本轮因果和构图方案重做。层数、图层数量和可通关不作为趣味性的验收结论。

通路铺面可开启近宽远窄透视，独立编辑入口宽度与出口比例；地面不会盖住通行人物。普通物体可以选择通路作为位置归属、拖动进度，使用普通 move 动作沿通路移动，并产生 contact/moved 等事件。未给物体名称编写专用判断。旧草稿保留，新示例仅新增版本槽。

当前字段、方向动画缺省和首版限制见 [分层 DSL 规范](docs/layered-dsl.md)，设计依据和修正前盘点见 [方向记录](docs/layered-street-direction.md)。旧三轴实验仍可由 `?sample=spatial-commute` 访问，详细记录见 [空间实验](docs/spatial-model.md)。

DSL v1 为原横版、v2 为三轴实验、v3 为二维分层。新编辑器读取三个版本，旧稿不自动转换为分层语义。主线旧编辑器不能运行 v2/v3。

公开 Pages 仍由 **main 稳定版 0.19.0** 发布，默认「里程碑 02 · 屋顶到亮窗」。本空间分支尚未合入 main。以下首关功能说明用于稳定版回归与能力对照。

## 试玩与编辑

1. 点击「运行」，主角从右上向左走。可以直接点击场景机关，也可以使用右侧同名按钮。
2. 按位置把握时机：参考操作时间为 **5 秒拉水管 → 9 秒点下方烟囱 → 12.5 秒天线 → 17.5 秒展开缓降物 → 20.8 秒抽支撑 → 27.5 秒放落物 → 41.5 秒关窗**，以页面模拟时间为准。完成一次约 45 秒。
3. 烟雾通路开始时完全隐藏；下方烟囱喷烟准备0.3秒后形成通路，持续5秒后隐藏。天线6秒后开始收回；缓降物展开6秒；生物真正被落物撞击后休息6秒。过早会恢复，过晚会错过。展开「关卡提示」查看顺序，暂停和单步可辅助观察。
4. 点击「返回编辑」，选择物体修改几何、能力、命名行为与连线，再运行验证。恢复时长在行为的延迟动作中编辑。

地图上方切换「逻辑实体」「美术资源」与「绑定校准」。前两者分别编辑几何/行为和图片/动画；校准视图叠加图片与逻辑轮廓，分别调淡，点选绑定，并可从任一属性面板跳到另一侧。换绑保留图片当前位置。图片显示大小可以和实体不同，改图不改变碰撞或规则。动画可关闭，暂停会冻结；机关的真实旋转、下落和碰撞始终由模拟决定。

美术资源模式提供可分类搜索的 CC0 素材库，可连续放置、点击/筛选图层、拖动和拉角缩放，并导入自己的 PNG/JPEG/WebP。布景可独立存在，也能让多张图跟随同一逻辑物体。首关的屋顶、墙面、窗户、阳台、招牌、垂藤和远景都是可编辑图层。来源、原始许可和项目补充素材见 [素材说明](assets/CREDITS.md)。

首关加入烟囱喷烟、通路浮现、旗帜轻摆、机关回弹、落地尘土、死亡倾倒与抵达反馈。喷烟输入是通路下方的绿楼烟囱，右侧旅店烟囱仅为布景。选中图片，在「动画与音效」中添加反馈槽：选择触发行为/事件、通用本体动画、粒子及音效，再调整时长、延迟、强度与挂点并预览；可复制到其他图层。自带9种整体运动、3种粒子与6种程序音效，也可导入短 WAV/MP3/OGG。一个行为可同时触发多槽，单独发声不必配置动画。死亡立刻停止玩法，有限的表现继续完成；暂停冻结、重置清理，总声音开关可静音。

左侧地图，右侧仓库、物体、逻辑、地图四个页签。仓库支持搜索和连续放置；点击已有物体手动检查属性、事件输出与行为输入，物体选取优先于交叉连线。滚轮围绕指针缩放，空格加拖动或中键平移，适合窗口复位。拖动物体时显示边缘/中心对齐线，Alt 暂停吸附；节点缩放，路面端点自然形成坡度。图层可临时隐藏、锁定。连线支持多路输入输出、折线和可拖动转接点。F1 查看 [Windows 快捷键](docs/editor-shortcuts.md)。

首次打开v0.17会整理本机工作区，下拉列表只留修正后的里程碑02；旧稿先归档到本机 `gothere.studio.v1.previous`，再从当前列表移除。整理仅执行一次，后续刷新保留编辑。「新建首关副本」和「新建」仍可手动创建测试副本/空白稿；以后升级不再以保留所有旧版本作为默认策略。草稿用JSON导出备份或交换。离线HTML直接用桌面浏览器打开，使用者无需安装npm。

画布工具栏新增默认开启的「路面吸附」，与「对齐吸附」分别控制。放置、拖动物体或拉伸底部节点时，约12屏幕像素内贴合真实路面、斜面或碰撞体顶面，拖动时用绿色高亮承托线；路面端点可相互衔接。Alt 临时关闭吸附，方向键与属性数值仍可精确微调。美术图片继续独立对齐，路面吸附只修改逻辑坐标。本次升级保留当前草稿。

连线可以直接拉出：选中物体后拖动右侧圆点到目标物体，或从右侧属性面板的具体事件圆点拖出；W 显示所有物体端口，左侧菱形支持反向接线。拖动时预览连线、高亮目标，并提供约18屏幕像素的命中容差。放到目标后，就近选择事件和行为；从具体事件拉到只有一个行为的物体会直接接好。也可点击端口，再点击目标，无需一直按住鼠标。Esc 或拖到空白处取消；支持多路输入输出，重复连接不累积规则，一次连接一次撤销。

## 内容模型

物品和生物使用通用 object；外观、能力、命名行为与事件分离。每个物体可定义多个行为，通过有限动作、条件、嵌套延迟和行为调用组成逻辑。连线是规则的可视化，没有第二份执行数据。

支撑、下落、撞击、支点旋转、持有缓降和落地反应都由同一内核处理。时机恢复由状态与 after 等通用动作组合，不按首关名称或对象 ID 编写专用逻辑。美术资源作为独立 scene 数据保存，绑定只读取实际状态，不决定伤害或承托。

[项目原则与路线](project.md) · [编辑器操作](docs/editor-engine.md) · [DSL 内容模型](docs/content-model.md) · [第一关参考拆解](docs/first-level-reference.md)

JSON 是当前 DSL，内含资源图层、反馈槽及导入的图片/短音效。整体动画可跨贴图复用；分层骨骼、自定义关键帧时间轴、命名配方库、可复用内容包、文本语法和程序生成仍是后续工作。当前为有限 2D 支撑与受控运动模型，不包含完整刚体动力学。

## 开发与验证

开发需要 Node.js 22.12.0 或更新版本：

```sh
npm ci
npm run dev
npm test
npm run test:coverage
npm run test:e2e
npm run build
```

访问 http://localhost:4173/ 。构建只生成同一编辑器的三个单文件入口：dist/index.html、dist/editor.html、dist/gothere-editor.html。推送 main 后，GitHub Actions 运行测试、构建并发布到 GitHub Pages。

浏览器测试使用 Playwright，无头运行，不弹出窗口。可使用本机 Edge，或执行 npx playwright install chromium 安装测试浏览器。测试产物保存在不提交的 artifacts/。

- src/core/：校验、动作、固定 60 tick/秒模拟与回放。
- src/editor/：首关数据、草稿历史、属性、行为及连线编辑。
- src/app/preview.js：不依赖 DOM 的预览控制。
- src/render/：逻辑图、资源场景与只读动画采样；保留旧几何表现兼容。
- assets/：CC0 素材文件、资源清单及作者许可。运行 node scripts/pack-assets.mjs 更新内嵌素材库。
- src/shell/editor.js：编辑器与预览组装。
- tests/fixtures/：旧场景仅作为内核回归素材，不进入产品或发布包。

单元测试覆盖各项能力、时机恢复、过早/过晚失败、遗漏操作、回放、历史、JSON、资源变换、反馈复用/确定性、死亡表现时钟、音频生命周期、打包与路由。浏览器测试覆盖首关通关、资源编辑、反馈配置/复制/试听/导入、缩放后的拖动/拉伸、吸附、平移、绑定校准、图层隐藏/锁定、旧稿保留及离线使用。自动验证不代替实际创作体验验收。
