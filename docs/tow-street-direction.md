# 借过一下：一个可直接试玩的街口事件

v0.24.0，2026-11-05。入口 `?sample=tow-street`，约24秒。用户目前能短时间试玩，不能花大量时间编辑；开发侧继续搭建场景与关卡，先交付可以直接判断因果和趣味的片段。公交站、模板练习及旧街区继续保留。

## 因果与画面

私家车占住早餐铺门口的人行道。一位路人指着车生气，主角照常往前走。点击路人后，他拿出手机；拖车从右侧画外倒入，在车前到位后抬起车头，沿道路向右拖走。车主反应稍晚，端着饮料从店门下来，追着自己的车跑出画面。主角继续步行到出口。场景不用文字标语解释。

启动后约3秒点击一次路人即可。不操作或太晚，车辆仍在阻路，主角接触后失败；提前操作可以成功，不强行重置车辆制造窗口。这里只验证一个事件，尚未完成三街区章节。

延续公交站的远景、整栋建筑、树池和连续街道，替换公交停靠铺面并增加9项同色板的原创 CC0 矢量资源。车、拖车、路人、车主均为独立绑定图层；背景和活动物体使用现有分组/组合。所有图片、状态覆盖、移动帧和反馈可在资源模式编辑，图片尺寸不决定伤害。

## 普通 DSL 表达

- 路人 click → 命名行为 call → 切换打电话状态 → after → 拖车 approach。
- 拖车实际 moved → 车辆 lift；车辆抬升实际 moved → 解除阻路状态，同时调用两车 haul 与车主 emerge。
- 两车同距离、同耗时移动，保持挂接的相对位置；拖车实际到达画外终点后隐藏。
- 车主延迟反应，从门口位置下降到人行道；实际 moved 后才 chase，追到画外后隐藏。
- 条件标记避免重复点击及首次到位误判为离场；规则顺序使新阶段在下一次对应到达事件时执行。
- 反馈槽绑定打电话、拖车到场、抬车和车主出现；关闭或删除动画、声音不改变结果。

没有修改模拟内核，也没有按名称识别车辆的渲染代码。挂接目前是创作者配置的协调动作，不是通用物理拖挂约束；改变两车行程时需要同步相关目标和时长。店门出来使用既有受控 move，尚无人物迈台阶的专用肢体动画。路面与拖车作业带用不同层归属区分深度；主角路线保持简单，以便单独验收此事件。

背景可以独立编辑。活动物体跨两条行走层并存在外部引用，不能把其中任一小组直接当作独立模板复制；本轮没有扩建模板系统或承诺自动对接。

## 验证与下一步

单元测试检查早/晚操作、重复点击、到位才挂接、抬升才清路、两车相对位移、画外离场、确定性回放、表现与逻辑隔离、历史/JSON。无头浏览器检查在线/离线实际点人、两视图通关、无操作失败、暂停冻结、图片编辑与撤销、保存重载和旧公交草稿保留；不弹出窗口。

试玩优先判断：能否看懂为什么点路人，清障是否连续，车主追车是否成立。自动验证不判定讽刺是否有趣。待反馈后，再考虑交警与乱穿马路行人、电瓶车与可放置路障；之后把经过验收的事件接成多层街区，程序生成继续暂缓。
