# 关系关卡实验 · v0.21

2026-11-02，分支 `codex/procedural-generation`。本轮根据录像研究搭建两个局部灰盒和一张原创小关，验证空间交接、姿态改变用途与同一物体的阶段复用。没有训练模型，没有修改随机生成算法，也不宣称完整复刻施工或碰碰车场景。

## 试玩入口

在本分支的本地或离线编辑器中，点击右上角「关卡实验」。默认选中《回来的路》；左侧可切换另外两个实验。浏览和切换不会写入工作区。

- **导入并试玩**：新增副本，以纯逻辑模式停在准备状态，点击「运行」出发。可以直接点击场景物体或右侧同名按钮，支持暂停、单步、重置和返回编辑。
- **编辑副本**：新增普通草稿，检查几何、能力、行为和事件连线。支持历史、JSON导出和普通资源绑定。
- **提示与解法演示**：默认折叠。演示前由真实模拟运行参考计划，成功后才导入并注入记录的输入。演示时禁止手动输入；返回编辑后可自由修改。

默认里程碑和 `milestone-02-v017` 工作区修订不变。已有草稿保留，草稿满时显示错误；不会自动覆盖旧稿。离线HTML包含全部实验，不要求联网。main与Pages仍为稳定版。

## 三张图分别验证什么

| 实验 | 关系 | 实际执行 |
| --- | --- | --- |
| 回来的路 | 同一活动路面在去程与返程连接不同高度 | 放平时跨到上层；倾斜时接到下层。人物从右侧显式高度通道换层、转向，然后再次经过同一承托物体 |
| 两次交接 | 一只开关分时调度两座运输平台 | 上台事件根据调度状态启动实际升降，到顶后按出口方向离开；第二座上升后折返。漏切换会走出平台并下落 |
| 换个姿势 | 同一个对象的危险、姿态、承托相互独立 | 命名行为关闭接触伤害并旋转物体。物体放平后端点接通缺口，人物真实踩在表面通过 |

前两个参考片段只提取录像支持的局部关系；没有复制原作资源、任意路线驾驶、完整侧向碰撞、多个停靠点或成对暗门。升降台确实移动载人；高度通道显式搬运人物，不冒充物理平台。

《回来的路》是原创设计。参考计划先放平去程，再倾斜返程，约20.8秒到达。模拟也找到一个自然替代方案：保持初始倾斜，先从下层过去，再放平后从上层回来，只需一次切换。两条路线都再次使用同一物体；不因为点击数少而人为封堵。

## 表达与验证

所有机制都由普通实体、pose/surface、transport、lift、条件、命名行为、rotate、set和after组成。两个有条件的切换行为延迟1tick写入状态，避免同一点击后面的规则看到新状态而立即切回。没有按关卡ID、物体ID特判引擎，也没有传送或预设胜负。

`src/experiments/play-plan.js` 是有限操作计划执行器：最多32次输入、最多3600tick，检查顺序和点击源，分段调用同一个模拟，保存真实录制和位置采样。支持一至两次输入，不套用旧生成器要求3～5次输入的筛选规则。位置采样只用于验收，不控制人物。

单元测试验证：三图DSL校验和编辑器往返；真实通关/回放；同一物体在两个方向和高度提供承托；显式下降、两座平台实际载人；无输入、漏返程切换、过早切换、改变尺寸或旋转时长后的几何结果；《回来的路》参考解法单次±24tick采样；合理替代路线；预算和错误输入。

浏览器测试覆盖本地与单文件离线：只读浏览、折叠解法、准备状态、场景和面板点击的手动通关、无输入失败、编辑副本、暂停/单步演示、原稿保留和草稿容量错误。全程无头运行。

验证命令：`node --test tests/experiments.test.mjs`、`node scripts/experiments-check.mjs`、`npm run test:coverage`。修改几何、速度或行为后，内置参考计划不自动重算，应重新试玩。

本轮完整验证：239项测试通过，9套浏览器检查全部通过；计入内核、生成、实验执行器等所选模块的行覆盖率99.73%、分支覆盖率93.88%。两个新增纯数据/模拟模块行覆盖率100%；DOM模块由浏览器检查覆盖，不计入上述行覆盖率。离线构建成功，约626 KiB。

## 下一步的判断

先由实际试玩判断是否需要观察关系、是否能理解两次经过的区别、失败后是否知道改哪里，以及等待是否过长。自动模拟只证明路线和部分失败样本，不证明趣味、唯一解或完整操作空间。

如果这组关系有效，再把「出发路线、返回路线、共享对象、换层/转向节点、改变对象的阶段」提取为带参数和约束的生成接口，搜索不同几何与组合；暂不增加独立障碍凑点击数，也不开始模型训练。
