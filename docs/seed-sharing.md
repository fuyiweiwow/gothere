# 地图种子与复现边界

状态：2026-11-06 · 设计约定。当前没有新增种子生成器或分享按钮。

## 是否与当前设计冲突

可以支持。作者 TypeScript 负责编排，生成后仍得到普通关卡 DSL；随机生成器也可以输出同一种 DSL，再交给现有校验、试玩、编辑和回放。目录资源只是编目，不在发现资源时执行作者行为，因此无需另外维护一种地图格式。

现在先约定可复现的输入和版本边界，继续完善手工创作与模板。种子不能自动带来有趣关卡，也不能代替主题、构图与因果设计。

## 种子分享至少携带什么

同一个种子只在相同生成环境下代表同一张图。未来分享描述需要：

| 字段 | 用途 |
| --- | --- |
| 分享格式版本 | 读取分享描述，不等同于关卡 schemaVersion |
| 生成器 ID、不可变版本及源码/依赖内容摘要 | 避免同名新版生成器改变结果；包括模板和规则库 |
| PRNG 算法与版本 | 固定随机数产生和字符串种子转换规则 |
| 种子字符串与生成参数 | 字符串避免大整数精度丢失；难度、尺寸、主题等参数显式记录 |
| 素材包 ID、不可变版本及内容摘要 | 固定资源标识、媒体字节、元数据与模板；内置素材也需版本 |
| 生成 API / 校验与模拟版本、输出 schemaVersion | 避免默认值、行为语义或空间解释变化 |
| 生成结果摘要 | 检测结果是否一致；不是缺失包的替代品 |

可以在产品中将这些信息编码为短分享码，或发布固定包后只显示种子。短码背后依然需要完整描述及可取得的匹配版本。缺失或不匹配的依赖应明确报错，不能静默换成最新版。

## 生成器的确定性契约

1. 后续提供显式注入的有种子 PRNG，生成器与模板从它取随机值；不依赖 `Math.random()`、当前时间、网络响应或操作系统目录顺序。
2. 同一输入以固定顺序遍历目录、候选模板与规则。对象 ID 从稳定的生成路径/索引产生，不能依赖时间或随机 UUID。
3. 媒体的解码速度、编辑器窗口大小与声音播放不参与逻辑生成；动画和音效读取生成后的数据。
4. 版本更新后保留旧生成器包，或明确升级成新的地图身份。用于摘要的序列化须固定对象键顺序，并保留有语义的数组顺序。
5. 验证同一描述反复生成、ZIP 往返、在线与离线输出摘要相同，再进行有解性和回放测试。模拟可回放本身不保证生成确定。

普通手写 JS/TS 仍可使用任意程序表达；只有遵守契约的生成器承诺种子复现。不要宣称任意作者代码输入一个数字就能复现。

## 手工编辑与自定义素材如何分享

种子只描述原始生成结果。生成后移动物体、改行为、加入自制图片或改动画，都不会自动进入种子。

早期直接导出完整关卡或项目 ZIP，最容易完整保留修改。后续可以分享“固定生成描述 + 手工修改补丁 + 必要素材包”，但要验证基础地图摘要；不将大量手工修改硬塞进所谓种子。项目 ZIP 可保留作者源码；完整关卡保存展开后的可玩数据，两者用途不同。

## 本轮落实的基础

v0.35.0 已提供确定的目录排序、保留移动前 ID、资源与源码分离、资源 ZIP 往返及沿用原校验和模拟。资源包内容摘要、固定 PRNG、生成器版本仓库、分享码解析和联网分发尚未实现。待可复用关卡模板成熟后，先选一种机制组合验证同种子复现，再扩展生成范围。
