# 编辑器快捷键

按 Windows 习惯使用 Ctrl；页面内按 **F1** 或点击工具栏「快捷键」打开同一套速查。当前为单物体选择。

| 按键 | 功能 |
|---|---|
| Ctrl+N | 新建草稿，保留原草稿 |
| Ctrl+O | 打开关卡源码 |
| Ctrl+S | 提交当前属性输入并保存草稿 |
| Ctrl+Z | 撤销 |
| Ctrl+Y / Ctrl+Shift+Z | 重做 |
| Ctrl+C / Ctrl+X / Ctrl+V | 复制 / 剪切 / 粘贴选中物体或路面 |
| Ctrl+D | 创建选中物体的副本 |
| Delete | 删除选中物体、连线或转接点 |
| F2 | 重命名选中物体；Enter 提交，Esc 取消输入 |
| 方向键 | 移动选中物体 1 单位；焦点在缩放节点时调整该节点 |
| Shift+方向键 | 移动物体或缩放节点 10 单位 |
| 连线节点上的方向键 | 按 10 单位网格调整转接点 |
| V / W | 切换选择 / 连线工具 |
| 拖动事件圆点 / 行为菱形 | 拉出连线；支持从输入端反向拖出 |
| 点击端口，再点击目标 | 无需按住鼠标也能连接；松手后选事件及行为 |
| Ctrl+F | 切换仓库并聚焦搜索 |
| 滚轮 | 以指针位置为中心缩放画布 |
| Space+左键拖动 / 中键拖动 | 平移画布；编辑时生效 |
| Alt+放置、拖动物体或拉伸节点 | 暂时关闭路面吸附；拖动时同时关闭边缘/中心吸附 |
| Alt+拖动图片 | 暂时关闭图片边缘/中心吸附 |
| Esc | 优先取消当前拖动，再取消工具或选择；模拟时返回编辑 |
| F5 | 运行模拟；模拟中重新运行或切换运行 / 暂停 |
| Space | 模拟中运行 / 暂停 |
| F10 | 暂停并推进一个 tick |
| Shift+F5 | 结束模拟，返回编辑草稿 |
| F1 | 快捷键速查 |

输入框中保留原生文字编辑快捷键，包括 Ctrl+A/C/X/V/Z/Y；不影响地图物体。属性输入按 Enter 提交、Esc 取消；Ctrl+S 会先提交输入再保存。中文输入法组合期间不触发编辑命令。JSON 和快捷键对话框打开时，地图快捷键停用。

物体剪贴板只在当前页面的草稿间共享，不使用系统剪贴板。复制包含尺寸、能力、外观数据和行为；自身行为中的物体引用会改为副本 ID。场景事件连线不自动复制，需要重新连接。若行为引用的外部目标在新草稿中不存在，粘贴会明确失败且保留原草稿。主角和终点为单例，不复制。

鼠标左键拖动物体移动，拖动选框边角缩放。开始拖动前会提交属性框的输入，拖动中保持鼠标捕获；移出物体或画布后松手仍可完成。一次拖动只增加一次撤销；Esc、窗口失去焦点或指针取消会还原拖动预览。

编辑器支持整套模拟快捷键，各视图中的操作相同。画布工具栏的「＋/−」缩放，「100%」恢复比例，「适合窗口」同时复位平移。快捷键不会触发额外桌面窗口。

「关卡源码」打开时使用源码快捷键：Tab / Shift+Tab 缩进 / 反向缩进，Esc 后 Tab 离开代码区；Ctrl+Shift+F 搜索项目，Ctrl+S 保存源码，Ctrl+Enter 生成并校验，F5 生成并临时试玩。F12 / Ctrl+点击转到定义，Alt+← 返回。代码中的撤销只修改当前文件；应用画布后可在画布 Ctrl+Z 撤销替换。源码和临时试玩操作不会触发背后的地图快捷键。

在「美术资源」模式，方向键/Shift+方向键微调当前图片或状态变体，Ctrl+D 复制图层，Delete 删除图片，F2 重命名图层，Ctrl+F 搜索图片，V/Esc 返回选择；Ctrl+Z/Y 共用文档历史。逻辑物体的 Ctrl+C/X/V 和 W 连线工具只在逻辑模式生效。拖动资源四角调整显示尺寸，旋转后的节点跟随图片；图片编辑不会改变实体碰撞或行为。

v0.23.0 选中模板组合时，方向键/Shift+方向键移动整个组合，Ctrl+D 复制成员、内部规则与动画音效，Delete 删除整个组合。含逻辑的组合只沿行走层水平移动，上/下键不改变层。Esc 退出连续放置或取消组合选择；展开部件后恢复单张图片的快捷键。暂不支持组合整体缩放或旋转。

「绑定校准」按其「编辑」选项使用对应一侧快捷键；点选绑定时 Esc 先取消点选。锁定图片不接受移动、删除或复制快捷键，可从图层列表解锁。图层显隐/锁定和校准透明度属于临时编辑状态。
