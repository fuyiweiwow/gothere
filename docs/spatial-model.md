# 空间模型实验：地面纵深与离地高度

日期：2026-11-04。版本：`0.20.0-spatial.2`。分支：`codex/spatial-2-5d`。基线：主线 `88a08fc4e64c418e69d306b6831007868c02c49a`。已实现下面描述的有限空间灰盒与逐像素遮挡；后续边界单独列出。

## 要解决的问题

当前横版内核以 x 表达左右，以 y 表达高低；路面是沿横向的支撑线，人物方向只有左右。资源的图层顺序改变绘制次序，不能表达物体在地面上的前后位置。游乐场和街道中通往远处的路线因此容易被误做成斜坡。

本轮目标是可编辑的有限 2.5D 空间：人物仍自动沿作者安排的路线前进，玩家通过环境干预解谜。参考录像的证据范围见 [梦游先生研究档案](../references/snoozleberg/README.md)，不宣称已经掌握原关卡全部路线和碰撞规则。

## 必须成立的语义

- **位置与画面分离**：世界位置为 `x`、`space.depth` 与 `space.height`。`height` 越大越高，`depth` 越大越远；物体本体高度仍是外层 `height`，与离地高度不同。空间文档为 `schemaVersion: 2`，包含 `spatial`；旧 v1 文档继续由原横版分支执行，旧 y 不改名、不重解释。
- **投影只负责显示**：第一步采用可配置的固定斜投影。相同高度向远处走会在画面上向上，升高也会向上，但两者的逻辑状态、接触和支撑不同。缩放、平移或更换投影不能改变模拟结果。
- **路线连接显式编辑**：路线节点和线段在世界空间中连接；画面交叉、不同高度的重叠都不会自动连接。离开支撑继续执行下落；不会为了到达目标自动寻路或等待。
- **接触与支撑使用世界几何**：画面上两个图形重叠不等于接触。同一位置的高架与地面分别提供支撑；车辆驶过桥下不能仅因投影重叠伤害桥上的人物。触发区同样需要明确纵深与高度范围。
- **遮挡和碰撞分离**：依据地面位置及物体空间关系组织前后遮挡；美术偏移、图片尺寸与手工绘制层级不能变成碰撞坐标。高架、地面与人物需要分别验证，不能仅按屏幕 y 排序宣称完成。
- **资源继续可创作**：普通资源可绑定人物、物体或路面，在空间锚点上叠加图片偏移、大小与动画。前后朝向允许选用不同资源；第一版不自动生成角色转身动画。
- **行为与事件继续通用**：空间中的移动、转向、到达、接触与支撑变化须有明确数据语义。不能通过关卡 ID、特定物体名称、隐藏传送或定时成功伪造路线。

## 最小验证场景

一张灰盒同时布置近侧人行道、向远侧延伸的连接路、远侧道路、移动车辆与一段高架。只使用足以检查空间关系的形状和配色，保留逻辑/资源两种编辑视图。

| 验证 | 必须看到的结果 |
| --- | --- |
| 横向后转入纵深 | 沿显式相连的路径走向远侧，再向外返回；同一地面上的 height 不因投影上下变化而改变 |
| 路线在画面交叉 | 未连接的路线不能直接换路；改变节点连接后才能进入另一条路线 |
| 前后遮挡 | 人物经过普通物体前后时遮挡关系相应改变；资源大小变化不改变脚点和碰撞 |
| 接触危险物 | 同一地面位置及相交高度范围内能够触发；仅画面重叠或处于另一纵深时不能误触发 |
| 桥上与桥下 | 地面车辆不误伤桥上人物；离开高架支撑后按世界高度下落，只有落到真实支撑才停止 |
| 修改与重放 | 改路线节点、纵深和高度后重新校验；保存/导入、暂停/单步、回放与离线执行保持同一结果 |
| 旧稿兼容 | 原里程碑 JSON 与行为无需手工改写，通关、失败、事件和表现回放保持原有结果 |

## 如何操作

默认入口打开「空间灰盒 · 近路与远路」。点击运行，再点击近侧移动物让它休息；人物先向远处走，沿斜坡上高架，向近处走过桥下移动物，最后离开高架落回地面并抵达终点。不点击近侧移动物会接触失败。

切换逻辑视图，拖动圆点改变路线在地面上的位置。选中圆点后，在右侧设置 X、地面纵深、离地高度和下一节点；地图页可添加节点。人物只会在真实抵达节点高度时沿 `next` 继续；仅从节点下方走过会保持当前方向，不会自动上桥或等待。

选择路面或物体可拖动、调整尺寸，或编辑占地深度与离地高度。路面右端离地高度不同便构成斜坡。拖动是在当前高度平面上反投影，不把向画面上方移动误当成升高。对齐开关控制路线节点吸附，路面吸附控制路面角点；容差按屏幕像素换算，Alt 暂停，结果只保存普通坐标。当前没有沿任意路面边缘的连续吸附。

美术资源页仍可添加图片、独立调整尺寸/偏移，并绑定主角、终点、物体或路面；绑定后跟随其投影脚点，图像几何不改变接触。绑定校准叠加逻辑范围。空间草稿使用独立存储键 `gothere.studio.spatial.v1`；原首关入口 `?legacy=1` 继续使用 `gothere.studio.v1`，两边不互相重置。导出 JSON 才能随离线编辑器带走自己的草稿。

## DSL 的最小结构

```json
{
  "schemaVersion": 2,
  "spatial": {
    "projection": {"originY": 550, "depthX": 0.18, "depthY": -0.65},
    "start": "near",
    "nodes": [
      {"id": "near", "x": 300, "depth": 60, "height": 0, "next": "far"},
      {"id": "far", "x": 300, "depth": 300, "height": 0}
    ]
  },
  "actor": {"x": 300, "speed": 75, "space": {"depth": 60, "height": 0}},
  "platforms": [
    {"x": 40, "width": 1100, "space": {"depth": 20, "depthSize": 330, "height": 0}}
  ]
}
```

这是字段片段，完整关卡仍需 id、名称、world、goal、entities 和 rules 等通用字段。路面可设 `space.heightEnd`；空间物体使用矩形占地，`space.depthSize` 默认为 24。投影为 `screenX = x + depth × depthX`，`screenY = originY + depth × depthY - height`。人物高度由支撑和重力决定，节点不是把人物传送到预设高度的命令。

## 当前边界与验证

空间模式支持普通物体、区域、压力板、开关、门、水平巡逻、矩形承托与碰撞能力；行为动作支持 set、hurt、invoke、enable、after，继续复用输入、信号、延迟、暂停、单步与录制回放。二维旧稿的旋转、持有、动态刚体与高度运输不自动变成空间能力，空间校验会拒绝这些尚未接入的组合。

绘制将路面、斜面与盒体拆为世界空间的面，逐像素插值纵深；人物和绑定图片作为脚点纵深上的直立图像共同参与深度测试。透明片元从远到近混合，轮廓线也接受遮挡，不再给整段坡道或长桥排一个顺序。绑定同一物体的图片仍以资源层级叠加，层级不覆盖世界前后关系。独立未绑定图片仍是背景。

一张图片只有一个空间锚点，不能自动推断图中多栋建筑或长桥各部分的纵深；这类资源需按空间部分拆开绑定。多方向角色动画、任意透视、自由导航、物理驱动车辆和世界空间粒子尚未完成。不把灰盒当作通用 3D 编辑器。

## DSL 兼容方向

| 数据 | 本分支新编辑器 | 主线 v0.19 旧编辑器 |
| --- | --- | --- |
| 横版 v1 | 原语义直接运行 | 原语义运行 |
| 上一空间预览的 v1 + spatial | 读取时升级为 v2，保留草稿、ID、资源和规则 | 不应使用，旧版可能忽略纵深 |
| 空间 v2 | 直接编辑、运行、导出 | 拒绝版本，不会错误按横版运行 |

旧横版不会自动补出纵深、支撑面或节点。空间模板继续使用原行为、事件、连线和资源抽象，程序生成器可直接生成完整的 v2 JSON；不需要针对这张图的专用脚本。旋转、持有等尚未移植的二维能力也不会因升级版本而自动获得。未知未来版本会被拒绝。草稿容器和操作录制的版本独立于关卡版本，仍保持各自的 v1。

单元验证包括投影独立、向里/向外行走、显式连接与错误高度节点、世界空间接触、桥上桥下、真实下落、坡面、压力板、草稿/回放、非法数据和吸附。深度缓冲另验证相交面、透明排序与共享边、图片透明洞、轮廓遮挡和画外裁剪。无头浏览器对上坡、拐弯、向近处过桥的 12 个位置采样胸部和腰部，覆盖两种视图的 48 个像素断言；另检查两种投影下的桥上/桥下与物体前后、绑定图片和缩放画布。编辑器回归包括节点拖动/属性、连续放置、资源绑定、历史、JSON/旧空间草稿升级、逻辑/资源两视图通关及离线零网络运行。旧里程碑继续执行原有浏览器回归。

本轮验证：249 项单元/集成测试通过；覆盖率目标（内核、深度缓冲、反馈/音频和指定交互模块）行覆盖率 99.79%、分支 92.12%、函数 96.88%，不代表全部 DOM 界面覆盖率。深度缓冲单独为行 100%、分支 92.19%、函数 100%。浏览器回归包含 7 组旧编辑器场景、空间编辑场景和逐帧遮挡场景；单文件构建约 636 KiB。所有浏览器均无头运行。
