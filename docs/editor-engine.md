# 关卡编辑器

本地开发版 v0.31.0 默认展示「上班路 · 还得去」完整街区，直接入口 `?sample=chapter`：三条街与两处向里连接，约一分钟，可直接试玩。先招呼公交载走队伍、靠近路口后点交警、进入中街后点生气的路人，再将路障拖到巷口、早餐拖到远街狗碗。公交和拖车在车道行动，行人半路被叫回，电瓶车从画外入场，终点在公司门口。两处通路铺面跟随逻辑端点，资源与逻辑仍独立编辑。站台、树池等独立布景归入对应行走层，属性中的「层内显示顺序」在该层内调整前后；背景图片统一位于各行走层下方。范围见 [整章记录](commute-chapter-layout.md)。新里程碑使用独立草稿槽，旧片段与旧稿保留。玩家拖放见 [能力记录](scooter-direction.md)，分层与通路进出见 [分层 DSL 规范](layered-dsl.md)。公开 Pages 仍是 main 稳定版；使用者无需安装 Node.js/npm。

## JavaScript 关卡源码

v0.31.0 提供 [画外工作区与 JS 项目](javascript-authoring.md)：画外选中、拖动和拉伸，一键设置入场／离场；源码使用左文件树、右代码区，地图、物体、事件和美术分文件，通过 `@gothere/core` 导入基础类，支持项目内 import、类继承和 ZIP 导入导出。旧关卡 JSON 与旧 JS 可载入转换。

顶部「JavaScript 关卡源码」（Ctrl+O）打开源码编辑器，提供语法着色及项目 API 的补全。生成和校验不会修改画布；应用后支持一次撤销，也可另存为新草稿。画布修改无法还原任意手写函数，重新从画布生成源码时会备份原源码。旧 JSON 可通过「载入关卡」导入转换。在线和离线功能一致。

逻辑视图选中普通物体，可配置「玩家可拖放」及允许的接收对象；另一个物体勾选「作为拖放接收点」并设置半径。运行时拖到接收点附近吸附，放错归位，Esc取消。拖放不会更改编辑草稿。`placed` 和「放错归位」可从事件槽接线；`enable` 可控制拖放/接收，表达时机窗口。暂停不接受拖放。接收范围使用逻辑基准点，不随图片尺寸改变。

## 素材模板与组合

打开本地 `?sample=templates`，或在美术资源面板点击「模板 → 新建街景练习」。背景包含远城、建筑、连续路面、站台、树与前景，保留为多个可编辑大块，不生成逻辑碰撞。练习是独立草稿，不覆盖原公交站或旧稿。

1. 选择「公交与候车队伍 · 含动作」，在画布约中间偏右点击放置。点击位置为公交基准 X；高度按所选行走层落地，不用对准一条像素线。工具支持连续放置，Esc 退出。完整背景按画布原位放置；独立建筑以落地基准放置。
2. 在模板页「场景中的组合」选择公交组合。拖动黄色框，或修改组合基准 X；方向键微调，Shift 加速，Ctrl+D 复制整个组合。活动组合沿当前行走层水平移动，部件的美术偏移在展开后调整。背景组合可以水平和竖直移动。组合不提供整体拉伸或旋转。
3. 点击「展开部件」中的门扇或乘客，进入现有图片属性。换图、尺寸、状态变体、逐帧动画与动画音效槽均能编辑；「查看逻辑实体」可转到行为。选中图片的「整体编辑」可以返回组合。单独挪动车门图片只改外观；若要改变实际上车位置，需要同时修改逻辑 move 目标，首版没有入口标记自动联动。
4. 点击「运行」，约3秒时点公交，检查上车、关门和驶离；暂停会冻结动画。返回编辑后可继续撤销、保存和导出 JSON。模板实例没有额外执行器，运行使用展开后的普通物体、规则和资源数据。

移动组合时，成员物体与指向它们的 move 目标一起平移；move 属性中的「组合移动时固定目标 X 到地图」可让离场等目标保留地图坐标，其他上车目标随组合移动。「解除组合」只移除共同编辑关系，保留所有图片、动画与逻辑。「删除整个组合」会同时删除成员及相关规则/反馈，请用撤销恢复。

首版提供4种内置模板，支持同一行走层的普通物体/区域、行为、内部连线及资源。实例独立复制，不向原模板回写。背景模板也可携带场景开始的循环动画/特效槽；当前街景背景保持静态。尚无自定义模板库、模板文件上传、自动识图、父子变换树或时间轴；外部逻辑引用无法直接复制为独立模板，需先纳入组合或解除该引用。

## 视图与绑定校准

地图上方可选「逻辑实体」或「美术资源」。逻辑模式编辑网格、几何、能力、行为与连线；资源模式通过图片图层搭建场景。两者读取同一草稿/模拟，切换不重置、不推进时间，也不更改物理或规则。

「绑定校准」将逻辑轮廓叠加在图片上，可以分别调节美术/逻辑透明度，并选择当前操作哪一侧。选中图片后显示其绑定目标和连接虚线。「在画布中点选绑定」可直接选逻辑实体，换绑保留图片的世界位置；Esc 取消。资源属性可跳到逻辑实体，逻辑属性列出关联图片，可直接跳回校准编辑。运行会取消尚未完成的点选，不改变草稿。

滚轮围绕指针局部缩放（50%～400%），＋/− 以可见区域中心缩放；100% 恢复比例，「适合窗口」同时复位平移。空格加左键拖动或中键拖动画布。编辑物体和图片时显示边缘/中心对齐线，吸附容差约6屏幕像素；Alt 临时关闭，或取消勾选「对齐吸附」。缩放和平移不进入文档历史。

「路面吸附」独立开关，默认开启。逻辑物体连续放置、拖动及底部节点拉伸时，在约12屏幕像素范围内贴合真实支撑高度；拖动时绿色线标出承托面。使用斜面、碰撞体顶面及已启用的物体承托面，排除自身与未启用的支撑。主角/终点按脚点，动态矩形按重叠区域最高点，支撑检测按配置的检测点计算。路面端点及物体承托面端点可吸附到附近支撑端点：整体移动保留坡度，拉端点保持另一端。高度通道的端点吸附也遵守开关及 Alt。图片仍按独立显示轮廓对齐，不会把图片当作支撑。

Alt 在放置、拖动或拉伸时临时关闭吸附。方向键微调及属性数值不强制贴地；高度通道的数值编辑保留已有端点匹配规则。吸附写入普通逻辑坐标，保存、JSON及撤销共用文档历史，一次手势一次撤销；不放宽运行时支撑判定。开关仅属于当前编辑页面，不写入DSL；升级不会重置已有里程碑草稿。

动画开关控制逐帧图片、通用本体动画与粒子；暂停时冻结。系统偏好减少动态效果时默认关闭，仍可手动开启。机关真实旋转、物体下落和持有位置不受此开关影响。「声音」可独立静音，不追补已错过的声音。

## 搭建美术场景

资源模式右侧「资源库」支持分类与搜索。选择图片后在地图连续放置，Esc/V 返回选择；放置不会跳转属性面板。「选中资源」编辑独立位置、图片宽高、附加角度、显示层级、透明度、水平翻转与可见性。四角节点缩放，节点随图片旋转；拖动、方向键/Shift+方向键微调图片。一次手势对应一次撤销，Esc、Ctrl+Z 或失焦可取消拖动。

下方「场景图层」可按名称筛选，以便选中被墙面、窗户等遮挡的图片。Ctrl+F 搜索资源，F2 改图层名称，Ctrl+D 复制图片，Delete 删除图片；Ctrl+Z/Y 共用文档历史。逻辑模式的物体剪贴板及连线快捷键只作用于逻辑。输入框保留文字编辑快捷键。

每个图层的「显/隐」仅临时影响编辑画布；「解/锁」阻止画布选取、拖动、缩放及移动/删除快捷键。仍可从图层列表查看属性并明确编辑字段。两者及校准透明度都不写入关卡、不改变运行表现；它们也不同于资源属性里的持久「显示此图片」。

「跟随逻辑对象」可选择独立布景、主角、终点、任意实体或路面。绑定后位置变为相对对象基点的偏移；图片跟随实际移动/旋转，宽高依旧独立。一个逻辑对象可以绑定多张图片。删除逻辑对象会清理对应图片；删除图片不会删除逻辑对象。模拟的场景点击区域根据可见绑定图片计算，实际承托/伤害仍按实体定义计算。

实体图片可选择「编辑状态变体」：覆盖该状态的图片、尺寸、偏移、角度或透明度。没有覆盖的字段继承基础资源；修改或拖动状态图片只修改当前变体。基础资源及状态变体均可启用逐帧动画，逐帧选择图片、增删帧并调整1～30 fps。图片替换默认显示静态图，启用动画后使用所设帧序列。这里没有精灵图自动裁帧或动画时间轴。

v0.22.0 普通空间物体可配置「移动中」变体，由实际 move 位移自动选择，并继承 active 状态未覆盖的字段。移动结束恢复状态图片；inactive 的隐藏仍优先。资源图层可填写「场景分组」，列表按组筛选，整组隐藏/锁定仅影响编辑，不影响运行。分组尚不提供整体变换。资源视图运行时按绑定图片的可见范围点选机关，逻辑视图仍按逻辑轮廓。

「平铺纹理」可铺设墙面，避免把一块砖图无限拉伸；「场景底色」在资源库中编辑。内置 Kenney CC0 素材及项目 CC0 补充图形，见 [来源与许可](../assets/CREDITS.md)。用户可导入 PNG/JPEG/WebP，单张最多256 KiB、2048×2048，总计512 KiB、24张；最多600图层。导入图片嵌入 JSON，离线 HTML 自带内置素材，均不依赖 CDN。

## 动画、粒子与音效

选择「美术资源」中的图片，在属性下方展开「动画与音效」。每个反馈槽组合一种本体运动、一种粒子和一个音效，可任选留空。内置挤压回弹、抖动、轻跳、后坐回弹、轻摆、呼吸缩放、浮现展开、淡出和倾倒；粒子有烟雾、尘土、火花。无需准备逐帧素材即可复用到不同贴图。

触发时机可选场景开始、任意物体的命名行为开始、物体事件、状态变化、主角死亡或到达终点。来源物体与目标图片相互独立，例如落地事件让主角图片挤压并扬起尘土。死亡可按原因过滤。多个槽选择同一触发可同步播放；需要阶段反馈时拆成命名行为，或选择真实 rotated/impact/done 等事件，动画不决定逻辑完成。

时长0.1～6秒，延迟0～10秒；可设置强度、音量、单次/循环、从头重播/叠加及结束保留姿态。本体变换绕图片底部中央叠加到真实姿态上；粒子挂点 X/Y 从图片左上0到右下1，随图片移动和旋转，方向上为−90°。当前没有脱离目标留在世界位置的粒子模式。粒子数量、颜色和方向可调。「预览」立即播放一次，忽略触发条件与延迟；循环也只预览一轮。「停止预览」恢复原图。「复制到其他图层」保留触发配置并更换目标，之后可独立编辑；还没有命名配方库或时间轴编辑器。

内置喷气、机关轻响、弹出、落地、抵达、失误6种程序音效。可导入 WAV/MP3/OGG，每段不超过256 KiB、8秒，最多8段、总计512 KiB；时长及解码有效性在试听/播放时检查。选入音效槽后用「预览」试听，自定义文件嵌入 JSON。浏览器声音从用户点击运行或预览后启用。暂停冻结正在播放的音频，重置、返回编辑或静音会停止声音。

死亡/成功立即停止玩法 tick，表现时钟继续到当前单次反馈结束，随后冻结循环效果及保留姿态，最长16秒（延迟10秒＋片段6秒）。暂停、切视图或重绘不重复触发声音。里程碑保存16个普通反馈槽：布景烟、旗帜、下方烟囱喷气、通路浮现、机关、落地、死亡和抵达。隐藏图片也可预览反馈：预览期间临时显示目标，停止即恢复，不改变其初始状态。反馈与几何共用历史、草稿、JSON和离线文件，不向实体写回显示变换。

## 试玩这一关

点「运行」后，直接点击地图机关或右侧同名按钮。主角始终前进，不能提前一次性布置所有机关。参考输入时序以模拟时间为准：

| 时间 | 操作 | 时机约束 |
| --- | --- | --- |
| 5 秒 | ⓪ 水管 | 绕支点拉斜，旋转完成才启用承托 |
| 9 秒 | ① 下方烟囱 | 喷烟准备0.3秒后形成通路，5秒后完全隐藏 |
| 12.5 秒 | ② 天线桥 | 旋转搭桥，6 秒后开始收回 |
| 17.5 秒 | ③ 缓降物 | 展开 6 秒，近身后才能持有 |
| 20.8 秒 | ④ 檐面支撑 | 抽掉支撑，檐面根据真实检测事件旋转 |
| 27.5 秒 | ⑤ 落物 | 真正撞击后生物休息 6 秒，过早会醒来 |
| 41.5 秒 | ⑥ 窗户 | 走近后区域事件开窗，再点击关闭；过早无法关闭、过晚会碰到 |

完整路线约 45 秒。展开页面「关卡提示」查看参考。时长是本原型的作者参数，不是对原作时序的断言。活动期间部分机关的状态条件会阻止重复叠加寿命。

暂停后点击只排队，下一次单步或继续运行时处理。单步推进一个 tick，即 1/60 秒。右侧观察主角、持有、物体状态、待执行动作和事件记录；机关按钮显示当前可触发状态及待恢复时间。场景点击区域随真实物体位置移动。

「返回编辑」恢复草稿，模拟不会覆盖创作。重置模拟回到初始状态，再点击运行。「新建首关副本」创建这一关的独立副本，「新建」创建空白草稿。

## 创作操作

左边地图，右侧仓库、物体、逻辑、地图四个页签。仓库支持分类和搜索，选中工具后可连续放置，面板不会自动跳到物体页。点击已有物体手动检查其属性和槽位；检查路面先用「选择」。Esc 退出放置。默认按点击高度放置，也可固定高度。

物体和路面可上下左右拖动；选框节点调整尺寸。路面左右节点分别调整端点，端点不等高自然成为坡面，拖动整体保留坡度，无需启用单独的斜面类型。手势开始前提交属性，鼠标移出画布后仍可松手提交，Esc 或失焦取消预览；一次拖拽对应一次撤销。方向键微调 1 单位，Shift 调整 10 单位。

路面可位于 Y=160～560，越小越高；配置右端高度形成斜坡。地图页签设置重力与最大下落速度。主角离开支撑后连续下落，落在下层后继续走，碰到非终点边界失败。

事件槽是输出，命名行为是输入，均显示已有连接。选中物体后，右侧圆点可拖出事件线，左侧菱形可反向拉出输入线；W 显示所有物体的端口。物体面板中具体事件的圆点可以直接拖向画布目标，行为菱形可反向拉向事件来源。拖动时显示预览、可连接目标及当前命中高亮，命中容差约18屏幕像素，端口保持26屏幕像素方便点取。

松手后在目标附近选择触发事件和目标行为；从具体事件拖到只有一个行为的物体会直接连接。多个行为不会默认接到第一个；没有行为的目标会提示先定义行为。也支持「点端口 → 点目标」，无需按住鼠标。Esc、拖到空白、窗口失焦或切换视图取消；拖线时 Ctrl+Z 先取消手势，未完成的线不保存。支持一对多、多对一、自连接及命名行为完成事件，重复连接不累积规则，一次新连接一次撤销；不改变物体位置。原来的「接线」按钮和规则页保留条件、延迟及动作顺序。双击已有线加入转接点，拖动或方向键整理，双击节点/Delete 删除；可恢复自动布线或过滤相关连线。

物体的选择区域优先于穿过它的连线，点击小物体直接打开物体面板。裸露线段仍可选择/双击；透明命中带固定为8屏幕像素，不随放大膨胀。路面位于连线下方，避免大面积路面遮住所有线段。

行为中「延迟动作」的秒数控制准备/恢复时长。烟囱行为负责准备后调用通路；烟雾通路行为负责激活、启用承托、延迟停用并恢复状态。修改时长后立即用同一模拟验证。没有只能通过代码修改的首关专用时间窗口。

F1 查看 [Windows 快捷键](editor-shortcuts.md)。支持保存、撤销/重做、复制/剪切/粘贴、副本、重命名、删除、搜索及模拟控制。输入框保留原生文字操作。

## 能力与数据

普通物体组合姿态/支点、独立承托、矩形碰撞、动态下落、支撑检测、巡逻、持有缓降或高度运输；外观不决定功能。物品和生物使用同一种 object，接触事件可调用攻击行为，行为执行伤害动作。

固定/铰接物体可用支撑检测点观察下方真实支撑，支撑消失只发事件，由连线决定是否旋转。动态物体自动检测承托并下落，受撞物的 impact 事件调用任意反应。主角安全落到实体上触发 actorlanded，可转向、收起或放下物品。

高度通道是 object 加 transport，支持上下端点及出口方向。宽度范围内与路面接壤即可，在 24 单位内自动吸附；缺少连接时指出具体端点。电梯未到位时主角不会等待。

完整字段、执行顺序、限制及兼容语义见 [内容模型](content-model.md)。当前没有完整刚体力学或任意脚本。

草稿保存在当前浏览器来源的 gothere.studio.v1，不跨设备同步。v0.17首次打开时，工作区整理为里程碑02单稿；旧工作区先写到 gothere.studio.v1.previous，列表中移除旧版本和其他测试稿。workspaceRevision 标记保证整理只执行一次，刷新保留后续编辑及手动新建稿。旧JSON仍可导入；归档是本机备份，不在列表中提供旧关卡入口。离线文件只包含编辑器，草稿须另行导出JSON。

## 实现与验证

保留参考文档中有用的边界：统一 JSON、独立确定性内核、草稿隔离、表现只读、单文件离线。不因工具较旧而迁移框架或包管理器。

src/shell/editor.js 只组装 UI 与预览；src/app/preview.js 不依赖 DOM；src/render/diagram.js、scene.js 和 resources.js 读取文档/快照，模拟仍在 src/core。首关布景只在 first-scene.js 中作为数据生成；渲染器不识别楼房或机关名称。旧示例只存在于 tests/fixtures，构建不会包含它们。

npm test 验证规则、空间、时机、回放、草稿、打包和路由；npm run test:coverage 检查内核覆盖率；npm run test:e2e 在后台无头浏览器验证编辑、首关通关、动画、资源、画布缩放/平移/吸附、绑定校准、隐藏/锁定、升级和离线操作。开发运行 node server.mjs，打包 npm run build。

这些检查证明自动流程可以完成。可发现性、可读性和创作流畅度仍需实际试玩反馈；资源包交换、精灵图裁帧、文本 DSL 和程序生成尚未实现。
