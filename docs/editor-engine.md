# 纯逻辑编辑器 · v0.10.0

目标：直接编辑和验证规则，不依赖游戏首页、关卡选择或美术表现。使用者只需浏览器；开发者才需要 Node.js/npm。

## 打开与操作

- 在线：[直接进入编辑器](https://fuyiweiwow.github.io/gothere/editor.html)。
- 离线：[单文件编辑器](https://fuyiweiwow.github.io/gothere/gothere-editor.html)。保存为 HTML 后直接打开，也可在页面点击「下载离线编辑器」。草稿用 JSON 单独备份。
- 开发：`node server.mjs` 后访问 `http://localhost:4173/editor.html`。

左边是几何地图，右边是仓库、物体、逻辑、地图四个页签。仓库中选择物体后，可以连续点击地图放置，工具会保持选中，面板也不会自动跳到物体页。地图上的机关可直接点击或拖动来选择、检查属性和事件槽；路面覆盖支撑区域，需切换「选择」工具再点击检查。检查后可继续在仓库挑选工具。纯编辑器默认按点击高度放置，工具栏可切换固定高度；直接修改「放置在 Y」也会切换为固定高度。路面和物体均可上下左右拖动，方向键每次调整 1 单位，Shift+方向键调整 10 单位。

「路面 / 平台」可放在任意支持的高度（Y=160～560），不是画布底边。这里的侧视高度对应多层/Z 轴空间，Y 越小越高。路面可勾选「斜面」，设置左右端高度；勾选时同时为地图开启重力。主角沿相接路面行走，失去支撑后保持水平速度下落，落在下层后继续走。地图页签可编辑重力和最大下落速度；未开启重力的旧地图沿用缺路即失败。

选中物体后，拖动选框的八个节点调整宽高；水平路面左右节点调整长度，斜面左右节点同时调整该端的位置和高度，另一端保持不动。拖动路面整体保留坡度。节点也支持方向键调整 1 单位，Shift+方向键调整 10 单位。拖动前先提交属性输入，拖动中预览并保持鼠标捕获，移出画布后松手仍会提交，Esc 或窗口失焦取消预览。松开只记录一次历史，尺寸随 JSON 与草稿保存。普通物体的高度用于几何显示和选择，接触按脚底高度和水平范围判断；没有任意二维刚体碰撞。

按 F1 或点击「快捷键」查看操作速查；完整定义见 [Windows 编辑快捷键](editor-shortcuts.md)。Ctrl+S 保存，Ctrl+Z / Ctrl+Y 撤销/重做，Ctrl+C/X/V 复制/剪切/粘贴，Ctrl+D 创建副本，F2 重命名。物体剪贴板复制定义与行为，场景连线需重新连接；文本输入保持原生操作。

仓库「高度通道」是普通 `object` 加 `transport: {type:'vertical',toY,speed}`。普通物体也可在属性中勾选「高度移动能力」，再设置上端高度、速度和上下出口朝向；外观不决定功能。拖动上下节点调整端点，距离 24 单位内自动吸附宽度范围相交的路面。上/下端均会显示已连接或未连接，画布端点以青/红色提示；缺少连接时明确指出端点高度。端点不再要求中心位于路面，路面搭到通道任意部分即可，主角在出口对接实际路面位置。完整上下跨度至少 40 单位；没有相交路面时保持可编辑草稿，运行前需补齐连接。

高度能力使用 active/inactive 状态控制新进入；已进入者完成当前运输。支持「抵达出口」事件连线。当前与左右巡逻互斥，启用前先关闭巡逻；关闭高度能力前先移除「抵达出口」连线，避免丢失规则。旧 `kind:'ladder'` 数据保留兼容。

接线时从事件槽点击「接线」，选择目标及其行为，再点击「连接」。双击线添加转接点，拖动或方向键整理；双击节点/Delete 删除。连线是规则的投影，调整排线不改变执行逻辑。规则页保留条件、延迟及动作顺序。

「运行」使用当前草稿的副本，右侧切为模拟观察。「单步」推进一个 tick（1/60 秒）；暂停后的点击会排队，下一次单步/运行时生效。可通过右侧按钮或几何地图点击事件源。观察主角位置、持有物、物体状态、延迟队列和已有状态变化日志。「返回编辑」恢复草稿，模拟结果不会覆盖它。

五个示例覆盖持有条件/延迟/行为完成事件、多层运输、生物行为与伤害、斜坡与下落、旋转承托面。第一例无需点击即可到达；多层运输需先召回电梯，未到位时主角会继续前进并掉落。

[斜坡与下落](https://fuyiweiwow.github.io/gothere/editor.html?example=slopes) 可直接运行：沿上层斜坡下降，走出边缘落在下层，再走到终点。可选中斜面修改坡度，或暂停/单步观察下落和落地日志。起点/终点高度需与实际路面一致；关闭重力但保留斜面时会提示校验问题，草稿仍可编辑。

[旋转承托面](https://fuyiweiwow.github.io/gothere/editor.html?example=rotation)：运行后点「释放机关」，普通翻板绕左端转为真实斜面，旋转结束事件打开出口。选中翻板可编辑初始角度、支点比例（0 左端、1 右端）、承托开关和行为中的目标角度/持续秒数；左右节点随真实端点定位，拖动时保持另一端位置。主角在旋转面上会随面移动并继续走。也可从仓库添加普通物体，勾选「姿态与旋转」，按需启用承托，再添加旋转行为和事件连线。

姿态不强制产生路面，承托不随 active/inactive 隐式改变；持有时承托暂停。角度限 -75～75 度，与巡逻可组合，与高度通道暂互斥。旋转结束用独立事件槽，行为完成仍表示命令/延迟调用执行完毕。当前未实现一般物体下落、自动支撑丢失、撞击或持有物缓降；完整参考首关仍待这些通用能力补齐。

「生物行为与伤害」在 Y=520 的下层路面和 Y=300 的上层路面之间放置带高度移动能力的普通物体。上层的巡逻生物是普通 `object`，定义「开始巡逻 / 休息 / 攻击」三个行为；感应区唤醒它，接触事件调用「攻击」，攻击行为执行 `hurt` 动作。没有新增敌人类型，也没有设置直接接触致命属性。运行后会受到攻击；重置后先点击「停止机关」，生物休息且感应区关闭，即可通过。修改攻击行为的动作便可改变交互，不依赖外观。

纯编辑器使用独立草稿键 `gothere.logic-editor.v1`，旧游戏工坊使用 `gothere.editor.v1`。二者共用 schemaVersion 1，可互相导入 JSON。导入包含贴图的旧关卡时保留其数据，但几何视图不加载或显示贴图；纯编辑器不展示上传贴图控件。草稿只保存在当前浏览器/文件来源中，不跨设备同步。

## 对参考方案的取舍

参考朋友提供的 design.md 与 architecture.md，采用其中能直接帮助原型的边界：

| 建议 | 本次落地 |
|---|---|
| 数据作为唯一事实源 | 编辑器、JSON、预览与原游戏沿用同一关卡格式；新增内容可直接导入，无需每关构建 |
| 表现与规则分离 | 新增 `src/render/diagram.js`，只读文档/快照；不导入游戏场景、关卡合集或图片 |
| 内核独立、确定性执行 | 继续共用 `src/core/engine.js`；`src/app/preview.js` 提供无 DOM 的预览控制 |
| 独立入口与平台组装 | `src/shell/editor.js` 组装编辑 UI、几何显示和预览；原游戏入口保持兼容 |
| 离线与内容隔离 | 分别构建游戏和编辑器单文件，只发布必要静态产物 |

以下建议保留为后续方向，不在本次一次性重写：

1. **注册表、可组合能力与应用写入服务**：有价值，是下一步。先用实际创作反馈固定字段/操作，再逐步替换类型分支及 UI 回调。当前类型仍是有限的，不支持仅导入数据便注册全新底层动作。
2. **独立可编辑/可运行校验**：当前继续使用草稿模型与现有运行校验；草稿模型容许未完成几何。后续将它们收敛到明确的校验模式。
3. **文本 DSL、种子、生成器**：建立在稳定数据与操作接口之上，暂不同时实现。
4. **完整内容包、主题包、兼容矩阵、CLI/Agent 协议**：等有具体需求再补。当前不引入并行的数据版本体系。
5. **pnpm/Tailwind**：可作为团队工具选择，但更换它们不会直接完善编辑逻辑。现有原生模块、npm 脚本和静态 GitHub Pages 已能交付最小原型，保持这条路径。

`npm` 是开发中的包/任务工具，不是用户安装要求，也不等于发布方式。发布交付的是自包含 HTML，没有运行期包下载或 CDN 依赖。

## 验证

`npm test` 验证数据、内核、预览操作及打包/静态路由。`npm run test:logic-editor` 在后台无头浏览器中验证直接进入、放置、行为与接线、排线、历史、持久化、JSON、单步/暂停、持有/延迟、多层运输、离线及下载副本。`npm run test:surfaces` 验证坡度属性、端点双轴拖拽、重力设置、撤销/重载、连续下落落地和离线完成路线。`npm run test:rotation` 验证姿态、支点、旋转动作/事件槽、端点拖动、历史/重载及在线/离线通关。原游戏通过原有 E2E/工坊/连线回归检查。

这些检查证明自动流程可运行；编辑器是否顺手仍需使用者实际创作验收。此版本未提供完整条件失败/行为调用追踪、任意自定义能力、文本 DSL 或随机生成。
