# 无字主题试作 · 一定要打上卡

2026-11-03，v0.23.0-experimental，分支 `codex/procedural-generation`。

## 这次验证什么

用户认为送桃小样已证明技术链路，但路线过于直白、场景单薄，也没有期望的荒诞现实影射。本轮尝试用户提出的中国上班路：主角持续走向公司，交通参与者各行其是，用环境、空间与反应建立情境。关卡场景不使用说明文字、对白、标语或总结笑点的结语。

这是手工创作的第一张主题验证图，尚未进入随机生成器。保持原有默认里程碑与草稿；「关卡实验」增加《一定要打上卡》并默认选中，送桃与三张灰盒仍可手动导入。

## 空间与反应

同一条街的主要通行高度为天桥200、候车亭/车顶280、人行道380及地下通道540。主角先经过候车亭与公交车顶，沿右端检修坡道下行，再从同一条车流下方折返，搭维修平台回到天桥，最后进入公司。

| 可见情境 | 普通DSL表达 | 当前范围 |
| --- | --- | --- |
| 电瓶车穿行人行道，行人被挤出直接路线 | object + patrol + contact，卸货板 rotate + surface | 人物实际受致命接触判定，避开路径由真实高度决定 |
| 公交关门发车，上班族追赶；红灯停车仍不开门 | 区域enter调用命名行为，move改变车与追车者位置 | 公交车顶为collider承托，位移实际载人；乘客登车和车门碰撞未实现 |
| 私家车压着横道，信号变化时挪车；看手机行人穿过车流 | 同一信号行为触发多个独立物体move | 是作者编排的反应，没有车辆互相避让、碰撞或完整交通AI |
| 地下绕行到维修井，上下路线在同一地点汇合 | 坡面、盖板surface/rotate、lift及board | 缺少路面或未到位轿厢时仍会下落，不自动等车 |
| 终于刷卡进入公司，窗内已是一排相同工位 | 真正hold工牌，区域holding条件、读卡器state、gate.open | 使用灯色与短音效收尾，无庆祝对白或讽刺标语 |

参考解法约41.2秒、4次操作；输入在参考时刻前后0.4秒的单项采样均可通过。可以提前准备，不把精确反应时间当作主要难度。提示与演示仍在目录中默认折叠，正常试玩不显示操作顺序。测试证明路线能运行，不证明题材表达已让人会心；本轮仍需用户判断画面、因果和反转是否成立。

## 无字试玩与可创作资源

「导入并试玩」进入收起编辑器面板的场景视图，保留运行/暂停、单步、重置、切换观察与返回编辑的图标按钮。无关卡说明、状态列表或文字反馈；可点击物在悬停/键盘聚焦时显示边框。辅助技术仍有按钮名称。◩切换回模拟观察，↶返回编辑；切换不推进暂停时间，不修改关卡文档。

126个可编辑图层、16个逻辑实体、12条规则、10个动画/音效槽。使用现有Kenney CC0建筑和角色，新增28张项目原创CC0矢量街道素材，以及4张由Kenney角色改色的白衬衫主角图片。街景、公司、车、人、路面和设备分别成层，不把整张底图或关卡对象名写进渲染器。许可见 [素材说明](../assets/CREDITS.md)。

美术仍为混合素材的概念搭建。静态候车者、公司窗内工位与远景仅作布景；活动公交、私家车、追车者、手机行人与电瓶车读取真实模拟坐标。分层与动静差别应在编辑器里可查，不能把静态布景数量当作独立行动者数量。

## 本轮新增通用能力

`move {target,x,y,ticks}` 为没有巡逻、动态重力或高度通道的普通object配置受控位移。它从实际当前位置启动，重复命令替换未完成位移，最后一帧精确到达终点，触发`moved`。可移动普通图形、collider或surface；踩在有效承托面上的主角/物体沿用已有支撑跟随。x/y为逻辑实体终点，ticks为1～3600，几何接受统一校验。

`done`表示行为命令和显式延迟完成，仍不等待物体实际移动；位移结束应连接`moved`，与旋转的`rotated`一致。位移不因inactive自动停止；拿起物体会取消其位移，持有期间忽略新的move。暂停、重置、回放与普通模拟共用时钟。旧lift增添click事件，使可点击的调用平台无需关卡专用控制器。

编辑器「物体→行为」或逻辑动作中选择「移动至坐标」，编辑目标、X/Y和秒数；事件槽与连线支持「位移结束」。DSL和内核不识别公交、公司、上班或实验ID。尚无运动缓动、任意路径、侧向刚体推挤或交通碰撞求解。

## 验证

`tests/translation.test.mjs`验证真实承托位移、结束事件、命令替换、暂停、重置、回放及非法组合。`tests/commute.test.mjs`验证DSL/草稿往返、实际车顶运输、地下折返、升降台、持有工牌刷卡、遗漏操作失败、几何不足失败、时机采样、移除美术后的模拟一致，以及素材许可和无文字SVG。

`scripts/commute-check.mjs`在本地与阻断联网的离线入口执行场景点击通关、暂停切换、无字界面、可编辑位移动作、撤销/JSON和旧稿保留。完整回归同时保留原里程碑、送桃和生成实验。

本轮256项单元测试与11组浏览器回归全部通过，浏览器场景均覆盖本地与离线入口。覆盖率命令所选模块合计行覆盖率98.17%、分支覆盖率94.30%，上班路的数据与场景模块均为100%。离线HTML约725KiB，内嵌187项资源，无需安装npm或连接外网。

下一步依据实际试玩反馈调整场面和节奏。当前没有承诺生成讽刺情节、扩大到关卡集或迁移引擎。
