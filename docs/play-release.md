# 正式试玩入口

v0.40.2 · 2026-11-10。供首轮外部试玩收集反馈。

编辑器顶部「正式游玩」进入 `?play`；开发服务器另有 `/play.html`。构建生成 `dist/play.html` 和 `dist/gothere-play.html`，后者可直接发给朋友，双击后离线运行。文件内包含代码、图片和程序音效，不需要 npm、服务器或网络；页面的「保存离线版」也可保存一份完整副本。

正式入口固定运行当前完成版「上班路 · 还得去」。不读取、不写入创作草稿，不显示攻略、操作窗口、对象名悬浮提示、连线或调试面板；控制只有出发、暂停/继续、重来和声音。空格或 Esc 暂停/继续，R 重来；切换窗口自动暂停，返回后由玩家继续。失败和到达先播放表现尾声，再提供重试。

入口复用 `createPreview`、同一模拟、分层渲染、反馈、声音和拖放队列，机关时机与编辑器一致。未创建第二套玩法代码。独立试玩包不包含代码编辑器、TypeScript 服务或编辑器界面；离线编辑器仍支持通过 `?play` 进入相同视图。

拖动物品进入有效接收范围后，物品提前吸附预览实际落点，并显示局部落点环；离开范围继续跟随指针。正式试玩在其他位置不显示接收点，不常驻提示。拖动中按 Esc 只取消这一手操作，不暂停；再次按 Esc 才按普通暂停处理。暂停、失焦或重来会取消当前手势，错误放置归位。松手后仍由模拟按原始输入坐标重新校验，吸附不放宽接收半径或冻结机关时机。

公开分享支持 GitHub Pages 和完整 HTML 两种方式。整章为 https://fuyiweiwow.github.io/gothere/play.html，公交站美术试作为 https://fuyiweiwow.github.io/gothere/gothere-painted-bus.html；无需安装、登录或启动本地服务器。localhost 仍仅供本机。正式入口与创作功能分开，之后可以继续编辑关卡，不影响已发出的固定试玩文件。

Pages 使用现有 main 发布流程，先运行自动测试，再构建并上传全部独立 HTML；version.json 记录版本和提交号，便于核对实际部署。源代码、生成素材的来源记录随仓库保存；录像、原始生图工作文件、个人参考目录和本机配置不进入静态站点。

美术补齐交警、行人、清障路人、车主、骑手、狗与车辆，共29份独立 CC0 资源，其中8份为修正后的主角倒地帧。保持既有资源 ID、画布尺寸与新样例中的绑定方式；狗吃饭使用独立低头姿势。倒地以 (56,90) 脚点校准，恢复裁切前的完整轮廓再平移贴地，图片与碰撞分离。

验收覆盖无操作失败及完整倒地、暂停/失焦/静音/重试、错误拖放归位、真实鼠标点击和拖放通关、草稿隔离、离线保存副本重新打开，以及在线、离线编辑器和静态预览入口。画风与趣味性仍以实际试玩反馈为准。

v0.40.2 已验证路障与早餐在接收范围两侧显示同一落点，离开后取消吸附、重新进入恢复，Esc 取消不触发暂停；四种正式入口均可通关。编辑器另验证放大后的逻辑/资源两视图与在线/离线一致。离线包已重建，未改变关卡数据或进行整章美术迁移。
