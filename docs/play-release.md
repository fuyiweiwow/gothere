# 正式试玩入口

v0.39.0 · 2026-11-09。供首轮外部试玩收集反馈。

编辑器顶部「正式游玩」进入 `?play`；开发服务器另有 `/play.html`。构建生成 `dist/play.html` 和 `dist/gothere-play.html`，后者可直接发给朋友，双击后离线运行。文件内包含代码、图片和程序音效，不需要 npm、服务器或网络；页面的「保存离线版」也可保存一份完整副本。

正式入口固定运行当前完成版「上班路 · 还得去」。不读取、不写入创作草稿，不显示攻略、操作窗口、对象名悬浮提示、连线或调试面板；控制只有出发、暂停/继续、重来和声音。空格或 Esc 暂停/继续，R 重来；切换窗口自动暂停，返回后由玩家继续。失败和到达先播放表现尾声，再提供重试。

入口复用 `createPreview`、同一模拟、分层渲染、反馈、声音和拖放队列，机关时机与编辑器一致。未创建第二套玩法代码。独立试玩包不包含代码编辑器、TypeScript 服务或编辑器界面；离线编辑器仍支持通过 `?play` 进入相同视图。

这次分享以完整 HTML 为单位。localhost 仅供本机；项目公开 Pages 仍是 main 稳定版，当前分支尚未发布。正式入口与创作功能分开，之后可以继续编辑关卡，不影响已发出的固定试玩文件。

美术补齐交警、行人、清障路人、车主、骑手、狗与车辆，共29份独立 CC0 资源，其中8份为修正后的主角倒地帧。保持既有资源 ID、画布尺寸与新样例中的绑定方式；狗吃饭使用独立低头姿势。倒地以 (56,90) 脚点校准，恢复裁切前的完整轮廓再平移贴地，图片与碰撞分离。

验收覆盖无操作失败及完整倒地、暂停/失焦/静音/重试、错误拖放归位、真实鼠标点击和拖放通关、草稿隔离、离线保存副本重新打开，以及在线、离线编辑器和静态预览入口。画风与趣味性仍以实际试玩反馈为准。
